# Sales Performance Dashboard 📊

## Overview

This project is an interactive Excel dashboard developed to analyze and monitor sales performance across different sales executives.
The dashboard provides a clear view of sales achievements, target completion rates, and performance gaps, helping businesses make informed decisions based on sales data.

## Business Problem

Organizations need a quick way to monitor sales performance and evaluate whether sales executives are meeting their assigned targets.

This dashboard helps answer:

- Who are the top-performing sales executives?
- Which employees achieved the highest target hit percentage?
- Who is farthest from achieving targets?
- How does sales performance compare across employees?
